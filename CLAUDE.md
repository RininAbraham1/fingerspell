# fingerspell

Solo, in-browser ASL fingerspelling practice app. Full plan: `docs/PLAN.md` (read it first).

## Rules
- Never add Co-Authored-By, "Generated with Claude", or any Claude attribution to commits or PRs. All work is authored by Rinin Abraham.
- One feature per branch and pull request, in the order of the plan. Keep each PR small and tested.
- Run `npm test` and `npm run build` before every commit.
- Frame the app as a fingerspelling *practice tool*, never a "sign language translator".
- No data leaves the browser: no servers, no uploads, no analytics.
